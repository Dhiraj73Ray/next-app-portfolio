# Dhiraj Ray — Portfolio

Personal developer portfolio. Warm Brutalist Swiss design built with Next.js 16, Three.js, and Framer Motion.

**Live:** [dhiraj73ray.vercel.app](https://dhiraj73ray.vercel.app/)

## Stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Styling:** Tailwind CSS v4
- **Animation:** Framer Motion, GSAP, custom canvas
- **3D:** Three.js via React Three Fiber (instanced meshes)
- **Icons:** Lucide
- **Content:** JSON-driven (`/data`)

## Features

- Custom canvas hero (interactive TechText, draggable glyphs)
- 3D particle crowd (instanced, ~40k particles at 60fps)
- Two-mode skills section: card catalogue + Rush Hour puzzle
- Two-panel projects browser with hover-preview and pin
- Radial AI Copilot wheel (mouse + touch gestures)
- Custom drafting cursor (crosshair, blueprint style)
- Contact dispatch slip with mailto fallback
